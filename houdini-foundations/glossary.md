# Glossary (Houdini Foundations 19.5)

**AOV / Image Plane** — extra render layer (direct, indirect, shadow, depth) (Ch3)
**Attribute** — data on points, primitives, vertices or detail (Ch1)
**Attribute Wrangle** — VEX code node for attributes (Ch1, Ch4)
**AutoDopNetwork** — DOP network created by shelf tools (Ch4, Ch7)
**Bullet** — rigid body solver, prefers convex shapes (Ch4, Ch7)
**Channel** — animated or referenced parameter, `ch()` (Ch1)
**CHOP** — channel operators, Motion FX (Ch4)
**Convex Decomposition** — splits concave pieces into convex hulls for Bullet (Ch7)
**Copy to Points** — instance geometry onto points; Pack and Instance for speed (Ch2, Ch5)
**DOP** — dynamics operators (Ch4)
**Dome / Environment Light** — sky/HDRI light (Ch3, Ch7)
**Extract** — Modify shelf tool: objectmerge copy in world space (Ch5, Ch7)
**File Cache** — writes geometry sequence to disk (Ch4)
**FLIP** — fluid solver (Ch4, Ch7)
**For-Each Named Primitive** — loop over pieces by attribute (Ch5)
**Geometry Spreadsheet** — attribute viewer `Alt-8` (Ch1)
**Group** — named selection; blank = all (Ch1)
**HDA** — Houdini Digital Asset `.hda` (Ch4, Ch6)
**HOM / hou** — Python object model (Ch4)
**Houdini Engine** — plug-ins to use HDAs in other apps (Ch6)
**Hydra** — USD viewport/render interface used by Karma (Ch3)
**Karma / Karma XPU** — Houdini's USD renderer; XPU is the hybrid GPU/CPU engine, alpha in 19.5 (Ch3)
**LOP / Solaris** — USD-based layout/lighting context, `/stage` (Ch3)
**Light Mixer** — per-shot light tweaks (Ch3)
**MaterialX** — open material standard used by Karma (Ch2)
**Material Library LOP** — where materials live in Solaris (Ch2, Ch5)
**MPlay** — image viewer (Ch3)
**Prune LOP** — deactivate prims by expression e.g. `$F>200` (Ch8)
**Principled Shader** — Disney principled uber material (Ch2)
**Pyro** — fire/smoke solver; Pyro Post Process, Bake Volume (Ch8)
**Ray** — projects points onto other geometry (Ch5)
**Retime** — remaps frames of a cached sim (Ch7)
**ROP** — render output node (Ch3)
**SDF collision** — volume collider from polygons (Ch8)
**SOP** — geometry operators (Ch1)
**Subdivision surface** — smooth render of polygons via OpenSubdiv (Ch2)
**TOP / PDG** — task operators / procedural dependency graph (Ch4)
**UDIM** — multi-tile UV layout (Ch2)
**USD** — Universal Scene Description (Ch3)
**VDB** — sparse volume format (Ch2, Ch4)
**VEX / VOP** — fast expression language / node version (Ch4)
**Vellum** — cloth, hair, grains, fluids, soft bodies including balloons (Ch4)
